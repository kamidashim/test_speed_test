# download-speed-test

Консольная утилита на Node.js для замера скорости скачивания. Делает заданное число (по умолчанию 10) последовательных запросов к адресу, каждый раз дожидается полного ответа и печатает статистику.

## Требования

- Node.js 20.3 или новее
- Внешних зависимостей нет, `npm install` не нужен

## Запуск

```bash
node speedtest.js [опции] <url>
```

Пример:

```bash
node speedtest.js "https://example.com/big-image.jpg"
```

Адрес рекомендуется брать в двойные кавычки: в Windows cmd и в shell символы `&`, `?` разрывают команду.

### Опции

| Опция | Описание | По умолчанию |
|---|---|---|
| `-n, --count <число>` | количество запросов | 10 |
| `-t, --timeout <мс>` | таймаут одного запроса | 60000 |
| `--json` | вывод в формате JSON | выключено |
| `-h, --help` | справка | |

## Пример вывода

```
Адрес: http://127.0.0.1:8766/big.bin
Запросов: 10 (последовательно)

#01: 5242.9 КБ за 49 мс
...
#10: 5242.9 КБ за 13 мс

--- Результат ---
Успешных запросов:   10 из 10
Среднее время:       15 мс
Медиана:             12 мс
Минимум / максимум:  6 мс / 49 мс
Скачано всего:       52.43 МБ
Скорость скачивания: 2818.97 Мбит/с (352.37 МБ/с)
```

Пример получен на локальном сервере, поэтому скорость завышена. На реальном адресе значения будут другими.

## Единицы измерения

- Скорость: **Мбит/с** (мегабиты в секунду) и дополнительно **МБ/с** (мегабайты в секунду). Мбит/с выбран основным, потому что в этих единицах провайдеры указывают скорость тарифа.
- Объём: **КБ** и **МБ** в десятичной системе (1 КБ = 1000 байт, 1 МБ = 1 000 000 байт).
- Время: миллисекунды.

## Как считается скорость

```
скорость = суммарный объём успешных запросов / суммарное время успешных запросов
```

Время запроса измеряется от отправки до полного получения тела ответа. Неудачные запросы в метрики не входят.

Первый запрос обычно медленнее остальных: он включает DNS, установку TLS-соединения и «холодный» кэш сервера или CDN. Поэтому для сравнения лучше смотреть и на медиану.

## Коды выхода

| Код | Значение |
|---|---|
| 0 | все запросы завершились успешно |
| 1 | хотя бы один запрос завершился ошибкой |
| 2 | неверные аргументы командной строки |
| 130 | прервано пользователем (Ctrl+C) |

## Тесты

```bash
npm test
```

Тесты используют встроенный `node:test` и локальный HTTP-сервер, доступ в интернет не нужен.

## Структура

```
speedtest.js       точка входа
src/args.js        разбор и валидация аргументов
src/download.js    один запрос: загрузка тела, таймаут, ошибки
src/runner.js      последовательный запуск запросов
src/stats.js       расчёт метрик
src/report.js      форматирование вывода (текст и JSON)
src/main.js        связывание модулей, коды выхода
test/              тесты
test-support/      тестовый HTTP-сервер
```
